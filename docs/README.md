# Pantheon Documentation

This directory contains the human-readable papers that govern Pantheon's construction. Code may implement these papers, but it does not silently replace them.

- [Construction](construction.md): how Pantheon is assembled.
- [Foundations](foundations.md): the enduring distinctions the runtime must preserve.
- [Software](software.md): the system's software shape and information boundaries.
- [Kernel 1 reportback](reportbacks/kernel-1.md): the first reportback and the template for its successors.

When a paper changes, the change should be deliberate, attributable, and reviewable.
